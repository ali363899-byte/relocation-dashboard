# 🎓 Student Relocation & Diplomatic Workflow Support Dashboard

A full-stack workflow management system engineered to track international student relocation, consular document verification, and residency approvals. Inspired by embassy liaison operations.

## 🚀 Key Features
- **Workflow State Management:** Tracks visa verification, university onboarding stages, and housing allocation.
- **Relational Persistence:** SQLite datastore managing structured records across diplomatic and academic entities.
- **Responsive Dashboard:** Bootstrap 5 administrative interface for record submission and status triaging.

## 🛠️ Tech Stack
- Python 3.10+
- Flask
- SQLite3
- Bootstrap 5
